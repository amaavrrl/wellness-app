# Wellness App 💖

Aplicación de wellness y hábitos para pareja.

## Funcionalidades actuales

- Registro de comidas
- Registro de actividades
- Dashboard de progreso
- Calendario mensual
- Tracking saludable
- Streaks
- Usuarios separados:
  - Amalia
  - Leandro
- Comidas compartidas entre ambos

---

## Tecnologías

- Next.js 15
- React
- Tailwind CSS
- TypeScript

---

## Instalación

```bash
npm install
```

---

## Ejecutar proyecto

```bash
npm run dev
```

---

## Abrir en navegador

```txt
http://localhost:3000
```

---

## Arquitectura actual

La aplicación utiliza:

- localStorage como persistencia temporal
- usuario activo (`activeUser`)
- filtrado por usuario
- comidas compartidas (`Ambos`)
